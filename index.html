How to use


  1. Budget: add each cost with the planned amount, then fill in the actual when invoices arrive. Positive variance means under budget.
    2. 

  2. Checklist: pick your event date. Tasks show a suggested deadline counted back from it. Add tasks specific to your event.
    3. 

  3. Run of show: add items in order. Times are calculated from the start time and durations.
    4. 

  4. Feedback analyser: export ratings from your survey tool, paste one question per box and read the summary.


Data is saved in this browser only. Use the download buttons to keep copies. Guides and a worked example are in the repository folders docs and examples. Sample data is fictional.
